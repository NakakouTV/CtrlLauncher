# CtrlLauncher

ゲーム制作サークルの展示向けに、複数のWindowsゲームを一覧から起動するWPFランチャーです。

## 開発環境

- Visual Studio 2026（.NETデスクトップ開発ワークロード）
- .NET 10 / WPF
- Windows 10またはWindows 11（x64）

`CtrlLauncher.slnx` をVisual Studioで開き、`CtrlLauncher` をスタートアッププロジェクトにして実行します。
画面は `MainWindow.xaml` と `Views/GameEditorWindow.xaml` からデザイナーで確認できます。

## 基本操作

1. 通常画面でゲームを選択し、「はじめる」を押します。
2. キーボードで `CTRL` と順番に入力すると管理モードになります。
3. 管理モードではゲームの追加・編集・再読込・終了ができます。
4. 「展示モード」を押すと、一時的な専用デスクトップへ切り替わります。
5. 展示モードでも `CTRL` と入力し、「終了」を押すと通常デスクトップへ戻ります。

展示モードでゲーム実行中に `Alt+Tab` を押すと、タスク切り替えを行わずゲームのプロセスツリーを終了してランチャーへ戻ります。

`time.txt` は交代案内までの分数です。未作成の場合は30分として自動生成されます。

登録画面では最初に実行ファイルを選択します。拡張子を除いた実行ファイル名が「ゲーム名」へ自動入力され、その後で自由に編集できます。ゲーム名は画面表示と `data`・`src` のフォルダー名に共通で使います。Windowsのフォルダー名に使えない文字や予約名を入力すると理由を表示し、追加・保存ボタンを無効にします。編集時にゲーム名を変えると、対応するフォルダーも安全に改名します。

既存ゲームの編集画面にある「このゲームを削除」は、`data/<ゲーム名>` 全体をWindowsのごみ箱へ移動します。ゲーム本体、画像、`setting.json` が対象です。

## ゲームデータ

```text
data/
└─ GameName/
   ├─ setting.json
   ├─ Game.exe
   └─ screenshot.png
```

ゲーム本体と画像をゲームフォルダー内へ置いてから登録すると、パスは相対パスで保存されます。
フォルダー外のファイルも登録できますが絶対パスになるため、別PCへのコピーには向きません。

DebugビルドはVisual Studioで確認しやすいようプロジェクト直下の `data`、`src`、`logs`、`time.txt` を使用します。
Releaseビルドは実行ファイルのあるフォルダーを基準にします。環境変数 `CTRL_LAUNCHER_HOME` を指定すると基準フォルダーを上書きできます。

詳しい構成は [CtrlLauncher/docs/ARCHITECTURE.md](CtrlLauncher/docs/ARCHITECTURE.md) を参照してください。
